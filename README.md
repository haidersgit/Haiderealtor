# haiderealtor

Website for Haider Chughtai, REALTOR® – eXp Realty, LLC. Live at https://haiderealtor.netlify.app

- `index.html` – the whole site (one page)
- `img/` – photos, named for Google
- `sitemap.xml`, `robots.txt` – for Google

## How the "Selling or buying?" form works
- On a phone, "Text me" opens the visitor's messages app with a note to 551-689-0265 already written. They hit send.
- Every submission is also saved in Netlify Forms and emailed to haiderealtor@outlook.com.

## Netlify settings
Forms → Form notifications → Email notification → haiderealtor@outlook.com
